プライバシーポリシー

最終更新日: 2026年9月29日

基本方針

AREITU は独自のサーバーを持ちません。開発者が運営するサーバーにあなたのデータが送られることはなく、開発者は あなたのデータにアクセスできません。訪問履歴データ（areitu.db、SQLite ファイル）はあなたの端末の ローカルディスクに保存されます。Google アカウントでサインインすると、このファイルはあなた自身の Google Drive の アプリデータフォルダ（appDataFolder）にも保存・同期されます。このフォルダは通常の Google Drive 画面には表示 されず、AREITU の OAuth クライアント以外からはアクセスできません。

AREITU 自身はデータベースを暗号化しません。端末上の areitu.db も Drive 上のコピーも、AREITU による 暗号化はされていません（Drive 上では Google による保存時の暗号化が適用されます）。

取り扱うデータ

  • あなたが指定したフォルダ内の写真から読み取った撮影日時と位置情報（緯度・経度）。写真ファイルそのものは外部に送信しません。
  • それらから作られた訪問履歴（日時、座標、推定した場所名）。
  • カレンダー連携を有効にした場合のみ、Google カレンダーの予定（タイトルと時間帯）。

リクエストする Google OAuth スコープ

  • https://www.googleapis.com/auth/drive.appdata: サインイン時に常に要求します。areitu.db をあなたの Google Drive のアプリデータフォルダへアップロード・ダウンロードするためだけに使います。同じ フォルダには、同期が競合した場合の退避コピー（areitu-conflict-日時.db）も作成されます。
  • https://www.googleapis.com/auth/calendar.readonly: 設定でカレンダー取り込みを有効にした場合にのみ 要求します。予定を読み取り、同じ時間帯の訪問の場所名を推定する手がかりにします。カレンダーを書き換えることは ありません。

データが端末の外に送信されるケース

以下は、AREITU がネットワークに送信する内容のすべてです。いずれも各送信先に接続元 IP アドレスが伝わります。

  • 逆ジオコーディング（既定で有効）: 場所名を推定するため、訪問の緯度・経度を OpenStreetMap の Nominatim（nominatim.openstreetmap.org）に送信します。設定で Google Places を有効にし API キーを 入力した場合は、緯度・経度を Google Places API（places.googleapis.com）に送信します。同じ座標が アプリ内の辞書に登録済みの場合は送信しません。
  • LLM による場所名推定（既定では無効）: 設定で LLM を選んだ場合のみ動作します。逆ジオコーディングで 施設名が得られない場合、または得られた名前がカレンダーの予定と一致しない場合に、次の内容をプロンプトとして 送信します: 訪問の開始・終了日時、緯度・経度、逆ジオコーディング結果の住所と施設名、同じ時間帯のカレンダー予定の タイトル。送信先は選択した LLM により異なります。
    • Ollama: 設定した URL（既定は同一端末の http://localhost:11434）。別のホストを指定した場合はそのホストに送信されます。
    • OpenAI: api.openai.com（あなたの API キーを使用）
    • Gemini: generativelanguage.googleapis.com（あなたの API キーを使用）
  • Google サインインと同期: サインインした場合、accounts.google.com、 oauth2.googleapis.com、www.googleapis.com（Drive、およびカレンダー連携有効時は Calendar）と通信します。サインイン中は、設定した間隔で areitu.db の同期が自動的に行われます。
  • アップデート確認: アプリは GitHub（github.com/ikeikeikeda66/AREITU/releases）から 更新情報を取得します。

上記以外の送信は行いません。広告や解析（アナリティクス）のための送信もありません。

Google ユーザーデータの取り扱い（Limited Use）

AREITU による Google API から受け取った情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータ ポリシー（Limited Use の要件を含む）に準拠します。

  • Drive のデータは、あなたのデータベースの同期にのみ使います。カレンダーのデータは、訪問の場所名推定にのみ使います。
  • Google ユーザーデータを開発者や第三者に転送しません。ただし、上記のとおりあなたが LLM を有効にした場合に限り、カレンダーの予定タイトルが、あなたが選んだ LLM の送信先に送られます。
  • Google ユーザーデータを広告に使いません。
  • 開発者が Google ユーザーデータを閲覧することはありません（開発者はデータにアクセスできません）。

データの保存場所

  • 訪問履歴データベース: OS のアプリデータディレクトリ内の areitu.db（識別子 com.areitu.desktop）
  • 同期状態: 同ディレクトリ内の google-calendar-state.json など
  • 設定: OS のアプリ設定ディレクトリ内の config.json（API キーは含みません）
  • OpenAI / Gemini / Google Places の API キーと Google のリフレッシュトークン: OS のキーチェーン（キーリング）のみ
  • Drive 同期時のコピー: あなたの Google アカウントの appDataFolder

データの削除方法

  1. AREITU の設定画面でサインアウトすると、端末のキーチェーンに保存された Google のリフレッシュトークンが削除されます。Google 側のアクセス権や Drive 上のデータは削除されません。
  2. Google アカウントのサードパーティアクセスのページで AREITU のアクセス権を削除すると、AREITU は以後あなたの Google データにアクセスできなくなります。
  3. Drive 上のコピーを削除するには、Google Drive の「設定」→「アプリの管理」で AREITU を選び、「非表示のアプリ データを削除」を実行してください（表示されない場合は、上記アクセス権の削除前に実行してください）。
  4. 端末上のデータを削除するには、AREITU をアンインストールし、OS のアプリデータ／設定ディレクトリの com.areitu.desktop 以下（areitu.db、config.json など）を削除してください。 キーチェーンに保存された API キーは、OS のキーチェーン管理ツールから削除してください。

プライバシーポリシー

最終更新日: 2026年10月19日

基本方針

AREITU は独自のサーバーを持ちません。開発者が運営するサーバーにあなたのデータが送られることはなく、開発者は あなたのデータにアクセスできません。訪問履歴データ（SQLite データベース）は iPhone 内のアプリ専用領域（iOS のサンドボックス）に保存されます。 Google アカウントでサインインすると、このデータベースのコピーがあなた自身の Google Drive の アプリデータフォルダ（appDataFolder）にも保存されます。このフォルダは通常の Google Drive 画面には表示 されず、AREITU の OAuth クライアント以外からはアクセスできません。

AREITU 自身はデータベースを暗号化しません。端末上のファイルは iOS のデータ保護の対象です。Drive 上のコピーには Google による保存時の暗号化が適用されます。

取り扱うデータ

  • あなたが許可した iPhone の写真ライブラリの写真から読み取った撮影日時と位置情報（緯度・経度）。写真そのものは端末の外に送信せず、アプリ内にも複製しません。
  • あなたがアプリで選んで取り込んだ Google Timeline（Takeout）のファイルから読み取った訪問の日時・座標・場所名。ファイル自体は端末内で読み取るだけで、外部に送信しません。
  • それらから作られた訪問履歴（日時、座標、推定した場所名）。
  • カレンダーへのアクセスを許可した場合のみ、iPhone のカレンダー（EventKit）の予定のタイトルと時間帯。予定の追加や変更は行いません。

リクエストする Google OAuth スコープ

drive.appdata のみを要求します。あなたの Google Drive のアプリデータフォルダに、訪問履歴データベース（areitu-ios.db）をアップロード・ダウンロードするためだけに使います。同じフォルダには、バックアップが競合して上書きする場合の退避コピー（areitu-ios-conflict-日時.db）も作成されます。カレンダーについては Google Calendar を使わず、iPhone の EventKit で読み取るため Google のカレンダー権限は要求しません。

  • https://www.googleapis.com/auth/drive.appdata

データが端末の外に送信されるケース

以下は、AREITU がネットワークに送信する内容のすべてです。いずれも各送信先に接続元 IP アドレスが伝わります。

  • 場所名の検索（逆ジオコーディング）: 訪問の場所名を求めるため、訪問の緯度・経度を Apple の MapKit に送信します（施設検索と住所検索）。Apple 側の取り扱いは Apple のプライバシーポリシーに従います。同じ座標がアプリ内の辞書に登録済みの場合は送信しません。
  • LLM による場所名推定（既定では無効）: 設定でオンにした場合のみ動作します。処理は iPhone 内蔵の Apple Foundation Models で端末内で行い、プロンプトは端末の外へ送信されません。非対応の端末では機能自体が使えず、LLM なしで動作します。
  • Google サインインとバックアップ: サインインした場合、accounts.google.com、 oauth2.googleapis.com（認可、トークン、取り消し）、www.googleapis.com（Drive）と通信します。サインインしている間は、同期のときに 6 時間に 1 回自動でバックアップし、設定画面の「今すぐバックアップ」でも実行できます。バックアップのたびに areitu-ios.db を Drive に保存します。

上記以外の送信は行いません。広告や解析（アナリティクス）のための送信もありません。

Google ユーザーデータの取り扱い（Limited Use）

AREITU による Google API から受け取った情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータ ポリシー（Limited Use の要件を含む）に準拠します。

  • Drive のデータは、あなたのデータベースのバックアップと復元にのみ使います。
  • Google ユーザーデータを開発者や第三者に転送しません。
  • Google ユーザーデータを広告に使いません。
  • 開発者が Google ユーザーデータを閲覧することはありません（開発者はデータにアクセスできません）。

データの保存場所

  • 訪問履歴データベース: アプリ専用領域（サンドボックス内のコンテナ）
  • バックアップ状態: 同コンテナ内
  • Google のリフレッシュトークン: iOS の Keychain のみ（この端末限定。他の端末やバックアップには移りません）
  • 設定: アプリの設定領域（AREITU は API キーを扱いません）
  • Drive のコピー: あなたの Google アカウントの appDataFolder（areitu-ios.db）

データの削除方法

  1. アプリの設定画面の「この端末のデータをすべて削除」を実行すると、この端末の訪問履歴データベース、同期とバックアップの状態、端末内 LLM の設定、Google のサインイン情報を削除し、Google からサインアウトします（Keychain のトークンを削除し、Google に取り消しを要求します）。Google Drive 上のバックアップは削除されません。
  2. 設定画面の「Google からサインアウト」を実行すると、Keychain のトークンを削除し、Google に取り消しを要求します。Drive 上のバックアップは残ります。
  3. Drive 上のバックアップを削除するには、Google ドライブの「設定」→「アプリの管理」で AREITU の非表示のアプリデータを削除してください。AREITU のアクセス権は Google アカウントの「サードパーティ アクセス」ページ（https://myaccount.google.com/permissions）から削除できます。
  4. AREITU を iPhone から削除すると、端末内のデータベース、同期とバックアップの状態、端末内 LLM の設定も削除されます。ただし iOS では、アプリを削除しても Keychain の Google トークンが残る場合があるため、アプリを削除する前に Google からサインアウトしてください。
